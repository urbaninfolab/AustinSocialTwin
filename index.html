Austin Social Map Information

About

This page provides an interactive map of social media data for Austin, Texas. The map displays real-time information including event likelihood, sentiment analysis (polarity and subjectivity), tweet density, and traffic conditions. This social-media powered digital twin helps visualize urban dynamics and social patterns across the city.

Credits

It was created underneath the Smart Cities Project, under the Good Systems Initiative in collaboration with The University of Texas at Austin. Additional support for this project comes from the Texas Advanced Computing Center.

Welcome to Austin Social Map

Guide

Layer Control: Click the layer icon to open the data filter menu. You can toggle different social media data layers:
  • Event Likelihood: Heat map showing predicted event probability based on social media activity
  • Polarity: Sentiment analysis showing positive/negative sentiment distribution
  • Subjectivity: Analysis of how subjective or objective the social media content is
  • Tweet Density: Heat map displaying the concentration of tweets across the city
  • Traffic Condition: Real-time traffic conditions from Google Maps
